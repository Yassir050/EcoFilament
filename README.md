# EcoTech — Interactive Presentation

A self-contained, offline-friendly presentation about turning suitable plastic waste into 3D-printing filament.

## Project structure

- `index.html` — presentation structure and bilingual content
- `css/style.css` — visual design, responsive layout, animations, and accessibility refinements
- `js/script.js` — navigation, language switch, countdown timer, fullscreen, and interactive quiz

## Run

1. Download and extract the ZIP file.
2. Keep the `index.html`, `css`, and `js` paths together.
3. Open `index.html` in a modern browser (Chrome, Edge, Firefox, or Safari).

No installation or external libraries are required.

## Controls

- Use Previous / Next or the left/right arrow keys to move between sections.
- Use the language control to switch between bilingual, English-only, and Arabic-only views.
- Click the timer to start or pause the 10-minute countdown.
- Use Fullscreen for presenting to a class.
- The audience discussion comes before the final quiz.
